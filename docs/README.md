# Dataset Documentation

This folder contains technical notes and statistics for the VN2V-Weather
dataset and its Re-ID benchmark splits.

| File | Purpose |
| --- | --- |
| `data.md` | Dataset notes and validation statistics |
| `dataset_statistics.md` | Annotation and class-distribution statistics |
| `reid_split_statistics.md` | Identity-disjoint train/val/test split and leakage-audit statistics |
| `figures/` | Generated dataset figures (produced by `scripts/make_paper_figures.py`) |
| `../methods/wicv/README.md` | WICV-Net method description |
